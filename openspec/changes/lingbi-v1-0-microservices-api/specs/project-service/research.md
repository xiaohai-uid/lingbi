# Project Service 微服务调研

## 调研概述

针对 Project Service（项目管理服务），调研了 10 个不同的技术解决方案，覆盖项目元数据管理、项目数据结构、项目导入导出、项目模板系统、项目协作、项目备份与恢复、项目统计、项目导入自外部、项目索引与搜索、项目版本管理等维度。

---

## 方案列表

### 方案 1: JSON + SQLite 混合存储
**链接**: 自定义实现

**特点**: 使用JSON文件存储项目元数据，SQLite存储文档关联和索引。

**优点**: 
- 简单灵活
- 易于调试和版本控制
- 与现有文件结构兼容
- 零依赖

**缺点**: 
- 需要自行实现一致性
- 并发处理能力有限
- 大数据量下性能下降
- 需要额外索引机制

**适配度**: 5/5

## 推荐方案

### 综合推荐：JSON + SQLite + 树形结构

**理由**：

1. **数据模型**：树形结构直观表示项目层级，易于用户理解。
2. **存储方案**：JSON存储项目元数据，SQLite存储文档关联和索引。
3. **导入导出**：支持Markdown目录导出和Pandoc多格式转换。
4. **版本管理**：SQLite快照版本管理适合频繁编辑场景。

### 实施建议

1. **阶段一**：使用树形结构数据模型组织项目
2. **阶段二**：实现JSON + SQLite混合存储
3. **阶段三**：添加Markdown目录导入导出
4. **阶段四**：集成Pandoc支持多格式转换

这个组合既保证了数据结构的清晰性，又保证了存储和搜索的高效性，能够满足灵笔对 Project Service 的各种需求。
