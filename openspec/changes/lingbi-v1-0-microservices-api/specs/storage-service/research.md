# Storage Service 微服务调研

## 调研概述

针对 Storage Service（存储服务），调研了 20 个不同的技术解决方案，覆盖SQLite变体、向量数据库、文档数据库、键值存储、混合存储架构、存储抽象层设计、数据迁移与备份、存储性能优化、数据一致性保证、存储安全等维度。

---

## 方案列表

### 方案 1: SQLite + extensions
**链接**: https://www.sqlite.org/

**特点**: SQLite扩展，支持向量相似性搜索。

**优点**: 
- 零依赖，嵌入式
- 事务支持
- 成熟稳定
- 与现有SQLite工具兼容

**缺点**: 
- 性能不如专用数据库
- 扩展需编译
- 并发能力有限
- 大数据量性能下降

**适配度**: 4/5

## 推荐方案

### 综合推荐：SQLite + vectors + LanceDB

**理由**：

1. **核心存储**：SQLite 提供零依赖的通用存储能力，事务保证数据一致性。
2. **向量存储**：SQLite vectors 扩展提供轻量级向量搜索，LanceDB 作为高性能备选。
3. **混合架构**：SQLite + 文件存储组合，适合灵笔的本地优先场景。

### 实施建议

1. **阶段一**：使用 SQLite 作为核心存储
2. **阶段二**：集成 SQLite vectors 扩展
3. **阶段三**：添加 LanceDB 作为高性能向量存储备选
4. **阶段四**：实现混合存储架构

这个组合既保证了存储的可靠性，又保证了向量搜索的性能，能够满足灵笔对 Storage Service 的各种需求。
