# Export Service 微服务调研

## 调研概述

针对 Export Service（导出服务），调研了 20 个不同的技术解决方案，覆盖PDF生成、EPUB生成、DOCX生成、多格式批量导出、模板系统、样式与排版、图片处理、分页与页眉页脚、封面生成、导出性能优化等维度。

---

## 方案列表

### 方案 1: WeasyPrint
**链接**: https://weasyprint.org/

**特点**: 开源的HTML/CSS转PDF库，支持现代CSS特性。

**优点**: 
- 支持现代CSS（Flexbox/Grid）
- 高质量PDF输出
- 支持图片嵌入
- 开源免费

**缺点**: 
- 需要外部依赖（libpango等）
- Windows安装复杂
- 性能一般
- 不支持JS渲染

**适配度**: 4/5

## 推荐方案

### 综合推荐：Flutter原生 + WeasyPrint + Pandoc

**理由**：

1. **核心导出**：Flutter原生导出（PNG/SVG）适合简单场景。
2. **PDF生成**：WeasyPrint 支持现代CSS，输出质量高。
3. **多格式转换**：Pandoc 支持100+格式，适合批量导出。

### 实施建议

1. **阶段一**：实现Flutter原生导出（PNG/SVG）
2. **阶段二**：集成WeasyPrint作为PDF生成后端
3. **阶段三**：使用Pandoc支持多格式转换（EPUB/DOCX/Markdown）
4. **阶段四**：添加模板系统和样式定制

这个组合既保证了导出质量，又保证了格式的广泛支持，能够满足灵笔对 Export Service 的各种需求。
