灵笔 LingBi 便携版
==================

1. 请先完整解压 ZIP，不要在压缩包预览窗口中运行。
2. 双击 lingbi.exe 启动，DLL 和 data 目录必须与程序放在一起。
3. 默认作品目录：%USERPROFILE%\Documents\灵笔
4. AI 功能需要在首次向导或“设置”中配置自己的 API Key。
5. 只从 https://github.com/xiaohai-uid/lingbi/releases 下载更新。

常见问题：
https://github.com/xiaohai-uid/lingbi/blob/main/docs/FAQ.md
