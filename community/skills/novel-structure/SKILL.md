# 小说拆解

> 分析小说的叙事结构、角色关系和情节走向，生成结构化拆解报告。

## 适用场景

- 学习优秀小说的结构设计
- 拆解竞品/参考作品的叙事手法
- 检查自己小说的结构完整性
- 为改编/续写提供结构参考

## 使用步骤

### 第 1 步：准备文本

将需要拆解的小说章节内容复制到灵笔文档中（建议 2000-5000 字效果最佳）。

### 第 2 步：发起拆解

在 AI 面板输入：

```
请拆解以下小说片段，分析：
1. 角色系统（主角/配角/反派设定与弧光）
2. 情节线（主线/支线交织）
3. 章节结构（起承转合、钩子位置）
4. 叙事视角（人称、视点切换）
5. 冲突类型与张力曲线

[粘贴文本]
```

### 第 3 步：查看结构报告

AI 输出包含：
- 🎭 **角色图谱**：每个角色的功能定位和弧光方向
- 📈 **情节曲线**：张力起伏可视化描述
- 🔗 **线索网络**：伏笔和呼应的对应关系
- ⚡ **钩子分析**：每个章节结尾的悬念设计

### 第 4 步：应用到自己的作品

```
参考上述结构，为我的小说设计类似的三幕结构：
- 第一幕：[你的设定]
- 转折点：[你想到的转折]
请给出详细的章节规划。
```

## 高级用法

### 多章节连续拆解
```
以下是我小说的前5章，请分析整体结构节奏：
第1章：[...]
第2章：[...]
...
问题：节奏是否有拖沓？哪里需要加速？
```

### 对标分析
```
请对比我的小说结构与《三体》第一部的叙事结构，
指出可以借鉴的技巧和需要避免的问题。
```

## 技巧提示

1. **分段拆解**：长篇小说按卷/章分批分析，最后汇总
2. **关注转折**：重点分析情节转折点的设计手法
3. **结合 Canon**：将角色分析结果存入正典系统
