# 多语言文学翻译

> 中/英/日/韩高质量文学翻译，保留文学风格，文化意象注释。

## 适用场景

- 将作品翻译为其他语言
- 翻译外文参考资料
- 保留文学性的同时确保准确性
- 处理文化特有概念的翻译

## 使用步骤

### 第 1 步：选择翻译方向

在 AI 面板输入：

```
请将以下中文翻译为英文，要求：
1. 保留文学风格和语气
2. 不是逐字翻译，是意译+风格还原
3. 文化特有概念加注释
4. 对话翻译要自然（符合目标语言习惯）

[粘贴文本]
```

### 第 2 步：指定风格参考

```
翻译风格参考：
- 如果是武侠：参考金庸英译本（Anna Holmwood风格）
- 如果是现代文学：参考余华英译本（简洁有力）
- 如果是轻小说：保持轻松口语化
```

### 第 3 步：处理文化概念

```
以下概念需要特殊处理：
- "江湖" → 不要直译"rivers and lakes"，用"the martial world"
- "内力" → "internal energy (qi)"
- "抱拳" → "cupped his fists in salute"
请翻译时保持这些统一。
```

### 第 4 步：校对回译

```
请将以下英文翻译回中文，我来对比是否丢失了原意：
[英文翻译结果]
```

## 支持语言对

| 方向 | 特点 |
|------|------|
| 中→英 | 注意时态、冠词、主被动转换 |
| 中→日 | 注意敬语体系、文体（である/です） |
| 中→韩 | 注意敬语等级、汉字词对应 |
| 英→中 | 注意长句拆分、被动转主动 |

## 技巧提示

1. **分段翻译**：每次 500-1000 字，质量更高
2. **术语表先行**：先确定专有名词翻译，再翻全文
3. **回译校验**：翻译完再翻回来对比，发现丢失的语义
