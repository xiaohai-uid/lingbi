# 大纲结构分析器

> 评估大纲完整性，匹配三幕式/英雄之旅/起承转合模板，节奏密度检测。

## 适用场景

- 检查大纲是否结构完整
- 选择最适合故事的叙事结构
- 检测大纲中的逻辑漏洞
- 从大纲生成章节规划

## 使用步骤

### 第 1 步：输入大纲

```
请分析以下小说大纲的结构：
1. 匹配最接近的经典结构模板
2. 检查完整性（是否有缺失环节）
3. 节奏密度是否合理
4. 转折点位置是否恰当

[粘贴大纲]
```

### 第 2 步：获取结构诊断

AI 会对比以下模板：
- **三幕式**：设置(25%) → 对抗(50%) → 解决(25%)
- **英雄之旅**：日常→召唤→跨越→试炼→回归
- **起承转合**：起(引入)→承(发展)→转(高潮)→合(收束)
- **网文节奏**：金手指→小打脸→升级→大打脸→循环

### 第 3 步：修复建议

```
诊断发现第二幕缺少"中点转折"，请建议：
1. 在什么位置插入转折
2. 转折的内容方向（3个选项）
3. 如何与前后情节衔接
```

### 第 4 步：生成细纲

```
基于修正后的大纲，生成前3卷的章节细纲：
每章包含：标题、核心事件、出场角色、情绪基调、章末钩子
```

## 结构模板速查

| 模板 | 适用类型 | 关键节点 |
|------|---------|---------|
| 三幕式 | 通用 | 25%触发/50%中点/75%低谷 |
| 英雄之旅 | 奇幻/冒险 | 12个阶段循环 |
| 起承转合 | 短篇/单章 | 4段式紧凑 |
| 网文爽文 | 长篇连载 | 3-5章一个小高潮 |

## 技巧提示

1. **先选模板再填充**：确定结构后再写细节
2. **转折点要早不要晚**：网文第一个转折在5%处
3. **大纲是活的**：写到一半发现不对就回来调整
