# 去AI味润色器

> 检测并改写 AI 生成痕迹明显的段落，句式多样化，情感注入，口语化处理。

## 适用场景

- AI 续写后的文本需要"去机器味"
- 让 AI 生成的内容读起来更像人写的
- 检测文本中哪些段落"AI味"最重
- 提升文本的自然度和文学性

## 使用步骤

### 第 1 步：识别 AI 痕迹

在 AI 面板输入：

```
请检测以下文本中的"AI味"段落，标记问题类型：
- 过度使用"然而""值得注意的是""总而言之"
- 排比句过多（三连排比）
- 每段结构雷同（总分总）
- 情感表达空洞（"不禁""竟然"滥用）
- 过于工整的对称句式

[粘贴文本]
```

### 第 2 步：查看检测报告

AI 会标注每个问题段落和具体问题类型，给出严重度评分（1-10）。

### 第 3 步：逐段润色

```
请将以下段落改写为更自然的表达：
- 打破工整的排比结构
- 加入口语化表达和语气词
- 句式长短交错，避免均匀
- 减少"然而""此外""总之"等连接词
- 加入具体的感官细节

[问题段落]
```

### 第 4 步：整体风格统一

```
以下是润色后的全文，请检查：
1. 是否还有残留的AI痕迹
2. 前后文风是否统一
3. 是否有过度润色导致不自然的地方
```

## 常见 AI 痕迹清单

| 痕迹类型 | 示例 | 修改方向 |
|---------|------|---------|
| 空洞感叹 | "他不禁愣住了" | 用具体动作替代 |
| 三连排比 | "是勇气，是智慧，是担当" | 保留一个，打散其余 |
| 万能连接 | "然而，事情并非如此简单" | 删除或用具体转折 |
| 过度总结 | "总而言之，这一切..." | 删除总结段 |
| 情感标签 | "一种复杂的情感涌上心头" | 用行为和细节暗示 |

## 技巧提示

1. **不要一次全改**：逐段处理，保持整体节奏
2. **保留好的部分**：AI 生成的情节逻辑通常没问题，只需改表达
3. **加入"不完美"**：人写的东西会有口语、省略、跳跃，适当加入
4. **读出声**：改完后读出声，不自然的地方一听就知道
