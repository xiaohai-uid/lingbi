# 章节节奏分析器

> 可视化章节节奏起伏，绘制情绪曲线，分析对话/叙述比例和张力评分。

## 适用场景

- 检测小说节奏是否有"拖沓"或"赶进度"
- 规划高潮和喘息的交替节奏
- 对比不同章节的张力分布
- 为修改提供节奏调整建议

## 使用步骤

### 第 1 步：提供章节内容

```
请分析以下章节的节奏：
1. 张力评分（每500字一段，1-10分）
2. 对话/叙述/描写比例
3. 情绪曲线（紧张→舒缓→高潮）
4. 节奏问题诊断

[粘贴章节]
```

### 第 2 步：查看节奏图

AI 输出类似：
```
段落1-3: 张力 4/10 [铺垫] ████░░░░░░
段落4-6: 张力 7/10 [冲突升级] ███████░░░
段落7-8: 张力 9/10 [高潮] █████████░
段落9-10: 张力 3/10 [收尾] ███░░░░░░░
```

### 第 3 步：多章节对比

```
以下是我小说前10章的概要，请分析整体节奏：
第1章：[概要]
第2章：[概要]
...
问题：
1. 是否有连续3章以上的低张力区间？
2. 高潮之间的间隔是否合理？
3. 开篇节奏是否够快？
```

### 第 4 步：获取调整建议

```
第5-8章节奏拖沓，请给出具体调整方案：
- 哪些场景可以删减
- 哪些冲突可以前置
- 是否需要插入新的紧张事件
```

## 节奏设计参考

| 位置 | 建议张力 | 说明 |
|------|---------|------|
| 开篇(1-3章) | 6-8 | 快速建立冲突 |
| 发展(4-8章) | 4-7 | 波浪式推进 |
| 中点(第50%处) | 8-9 | 重大转折 |
| 低谷(60-70%) | 3-5 | 喘息+铺垫 |
| 高潮(80-95%) | 9-10 | 最终对决 |
| 结尾 | 4-6 | 余韵收束 |

## 技巧提示

1. **波浪原则**：永远不要连续两章同一张力水平
2. **开篇黄金3章**：网文前3章决定读者去留，张力必须≥6
3. **喘息有价值**：高潮后的低张力段落用于角色成长和伏笔
