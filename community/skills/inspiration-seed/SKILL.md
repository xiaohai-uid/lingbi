# 灵感种子生成器

> 基于关键词/类型生成故事种子和情节框架，题材模板和"what if"假设推演。

## 适用场景

- 完全没有灵感时，让 AI 帮你头脑风暴
- 有一个模糊想法，需要扩展为完整故事
- 突破创作瓶颈，探索新方向
- 为短篇/长篇生成初始框架

## 使用步骤

### 第 1 步：输入灵感关键词

在 AI 面板输入你的初始想法，哪怕只是一个词：

```
我想写一个关于「时间循环」的悬疑故事，背景设定在民国时期的上海。
请生成 3 个不同的故事种子。
```

### 第 2 步：选择方向

AI 会生成 3-5 个故事种子，每个包含：
- 🌱 **核心概念**：一句话概括
- 🎭 **主角设定**：身份+困境+欲望
- ⚡ **核心冲突**：主要矛盾
- 🔮 **发展方向**：可能的故事走向

选择你最感兴趣的一个。

### 第 3 步：深化种子

```
我选择第 2 个种子。请扩展为完整故事梗概（800字），包括：
1. 世界观设定
2. 主要角色（3-5个）
3. 三幕结构大纲
4. 核心主题
```

### 第 4 步：生成章节框架

```
基于上述梗概，生成前 10 章的细纲，每章包含：
- 章节标题
- 核心事件
- 出场角色
- 章末钩子
```

### 第 5 步：开始创作

将生成的框架保存为项目大纲，在灵笔中创建对应章节开始写作。

## 高级用法

### What-If 推演
```
What if: 如果人类突然失去所有情感记忆，世界会怎样？
请从以下角度推演：
1. 社会秩序变化
2. 人际关系重建
3. 一个普通人的第一天
生成 3 个不同基调的故事种子（温暖/黑暗/荒诞）。
```

### 类型混搭
```
将「修仙」和「科幻」混搭，生成一个创新题材的故事种子。
要求：不是简单的"太空修仙"，而是找到两种类型的深层共鸣点。
```

### 反向灵感
```
我最讨厌的桥段是：失忆、穿越、系统流。
请避开这些，生成一个新颖的都市奇幻故事种子。
```

## 技巧提示

1. **越具体越好**：`时间循环+民国+上海` 比 `悬疑故事` 生成的种子质量高得多
2. **多轮迭代**：第一轮选方向，第二轮深化，第三轮细化
3. **组合创新**：让 AI 把两个不相关的种子合并
4. **保存灵感**：好的种子立即存入 Canon 正典的「情节」分类
