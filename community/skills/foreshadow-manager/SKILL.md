# 伏笔管理器

> 追踪伏笔的埋设、暗示和回收状态，DAG 可视化，回收提醒和关联章节索引。

## 适用场景

- 长篇小说中追踪大量伏笔线索
- 避免"挖坑不填"或忘记回收伏笔
- 规划伏笔的埋设和回收时间点
- 检查伏笔之间的逻辑关联

## 使用步骤

### 第 1 步：录入已有伏笔

在 AI 面板输入：

```
请分析以下章节，提取所有伏笔线索：
- 伏笔内容
- 埋设位置（第几章）
- 当前状态（已埋设/已暗示/已回收）
- 预计回收时间

[粘贴章节内容]
```

### 第 2 步：建立伏笔档案

将提取结果整理为 Canon 正典条目（类型：情节），格式：

```
伏笔名称：[简短描述]
状态：已埋设 / 已暗示 / 已回收
埋设章节：第X章
暗示章节：第Y章（可多次）
计划回收：第Z章
关联伏笔：[其他相关伏笔ID]
```

### 第 3 步：规划回收时间线

```
我有以下伏笔需要回收：
1. [伏笔A] - 埋设于第3章
2. [伏笔B] - 埋设于第7章
3. [伏笔C] - 埋设于第12章

请规划回收顺序和时间点，确保：
- 读者不会遗忘（间隔不超过20章）
- 回收时有足够的情感冲击
- 多个伏笔可以串联回收形成高潮
```

### 第 4 步：检查遗漏

```
以下是我小说的完整大纲（30章），请检查：
1. 哪些伏笔超过15章未回收
2. 哪些伏笔缺少中间暗示
3. 回收顺序是否合理
4. 是否有可以合并回收的伏笔
```

## 伏笔管理最佳实践

1. **3-5-15 法则**：埋设后 3 章内第一次暗示，5 章内第二次暗示，15 章内回收
2. **层级设计**：短线伏笔（5章内回收）+ 中线（15章）+ 长线（跨卷）
3. **串联回收**：高潮章节同时回收 2-3 个伏笔，形成"原来如此"的爽感
4. **误导伏笔**：故意埋设指向错误方向的线索，增加悬疑感

## 技巧提示

1. **及时录入**：写到新伏笔时立即记录，不要依赖记忆
2. **定期检查**：每写完一卷，全面检查伏笔状态
3. **读者视角**：问自己"读者还记得这个伏笔吗？"
