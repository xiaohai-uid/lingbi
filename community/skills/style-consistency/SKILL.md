# 文风一致性检查器

> 扫描全文检测文风偏移，标记风格不一致段落，分析句长分布、用词频率和修辞手法一致性。

## 适用场景

- 长篇写作中检测文风是否"跑偏"
- 多人合写时统一风格
- AI 续写后检查是否与原文风格一致
- 修改多轮后确认整体风格统一

## 使用步骤

### 第 1 步：建立基准风格

选择你认为最满意的 1-2 个章节作为"风格基准"：

```
请以以下文本为风格基准，提取风格特征：
- 平均句长
- 对话/叙述比例
- 常用修辞
- 段落长度分布
- 情感表达密度

[基准章节文本]
```

### 第 2 步：检测目标章节

```
以之前提取的风格基准为标准，检查以下章节的文风一致性：
1. 标记偏离基准的段落
2. 说明偏离方向（更口语/更书面/更冗长/更简略）
3. 给出修改建议

[待检查章节]
```

### 第 3 步：查看报告

AI 输出包含：
- 📊 **一致性评分**：0-100（80+ 为良好）
- 🔴 **问题段落**：标红偏离严重的段落
- 📈 **趋势图**：文风随章节变化的趋势
- 💡 **修改建议**：具体的调整方向

### 第 4 步：批量修复

```
请将以下段落修改为与基准风格一致：
[问题段落]
要求：保持内容不变，只调整表达方式。
```

## 技巧提示

1. **基准要稳定**：选择中期章节（非初期摸索也非后期疲劳）
2. **允许合理变化**：高潮章节节奏加快是正常的，不算偏移
3. **分批检查**：每次检查 3-5 章，避免上下文过长影响准确度
