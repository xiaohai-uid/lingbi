# 角色关系图谱生成器

> 自动提取角色互动并生成关系图，量化关系强度和变化时间轴。

## 适用场景

- 梳理复杂小说中的角色关系网
- 检测角色互动是否合理
- 发现被忽略的角色关系可能性
- 为角色关系变化设计时间线

## 使用步骤

### 第 1 步：提供角色文本

在 AI 面板输入：

```
请分析以下章节中的角色关系：
1. 列出所有出场角色
2. 标注两两之间的关系类型（亲属/敌对/师徒/恋人/盟友...）
3. 量化关系强度（1-10）
4. 标注本章中关系是否有变化

[粘贴章节内容]
```

### 第 2 步：生成关系图

AI 输出结构化关系数据：

```
角色A ←→ 角色B：师徒（强度8）→ 本章变为对立（强度6）
角色A ←→ 角色C：暗恋（强度5）→ 未变化
角色B ←→ 角色C：仇敌（强度9）→ 加剧
```

### 第 3 步：追踪关系变化

```
以下是第1-10章的角色关系摘要，请绘制关系变化时间线：
第1章：A-B 师徒(8), A-C 陌生(1)
第5章：A-B 师徒(6), A-C 好感(4)
第10章：A-B 对立(7), A-C 恋人(8)
分析关系转折是否自然，哪里需要补充铺垫。
```

### 第 4 步：存入 Canon

将角色关系信息更新到 Canon 正典的角色条目中，方便后续写作参考。

## 技巧提示

1. **分章分析**：每章单独分析后汇总，比一次性分析全文更准确
2. **关注变化**：关系不变=没有戏剧张力，每 5 章至少一次关系变化
3. **三角关系**：最稳定的戏剧结构是至少 3 个角色形成关系三角
