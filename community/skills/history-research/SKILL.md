# 历史考据助手

> 基于联网搜索验证历史细节准确性，朝代服饰/建筑/礼仪查询，时代用语检查。

## 适用场景

- 历史小说写作中的细节考证
- 检查服饰、建筑、饮食是否符合时代
- 验证历史事件时间线
- 避免"穿越"用语（如古代人说现代话）

## 使用步骤

### 第 1 步：提出考据问题

```
我的小说设定在北宋汴京，请考据：
1. 普通市民的日常服饰是什么样的？
2. 酒楼/茶肆的布局和经营方式？
3. 见面礼仪（不同身份之间）？
4. 货币单位和物价水平？
```

### 第 2 步：验证文本细节

```
请检查以下段落中的历史细节是否准确（背景：唐朝长安）：
1. 服饰描写是否正确
2. 称谓是否合规
3. 饮食是否穿越
4. 地名/官职是否正确

[粘贴段落]
```

### 第 3 步：获取替代方案

```
"她穿着一件旗袍走进大厅" — 这在民国时期是否合适？
如果不合适，请给出：
1. 正确的服饰描写
2. 3种不同身份女性的着装方案
3. 可参考的影视/文献资料
```

### 第 4 步：时代用语检查

```
请检查以下对话中是否有不属于[朝代]的用语：
- 现代词汇穿越
- 称谓错误
- 俗语/成语时代不符

[对话内容]
```

## 常见考据要点

| 类别 | 常见错误 | 注意事项 |
|------|---------|---------|
| 服饰 | 各朝代混穿 | 区分常服/礼服/戎装 |
| 饮食 | 出现后世食材 | 辣椒明末才传入 |
| 称谓 | 称呼制度混乱 | 避讳制度因朝而异 |
| 建筑 | 出现后世建筑形式 | 注意建筑等级制度 |
| 交通 | 旅行时间不合理 | 日行30-50里为常 |

## 技巧提示

1. **先大后小**：先确认大背景（朝代、地点），再考据细节
2. **允许虚构**：历史小说不是论文，大方向正确即可
3. **建立设定集**：考据结果存入 Canon，避免重复查询
