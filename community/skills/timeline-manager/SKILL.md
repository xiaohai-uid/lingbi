# 时间线管理器

> 追踪故事事件时间线，检测时间矛盾与断层，管理平行时间线。

## 适用场景

- 复杂叙事中追踪多条时间线
- 检测时间逻辑矛盾（如角色"分身术"）
- 管理倒叙/插叙的时间对应关系
- 确保季节、天气、节日等时间标记一致

## 使用步骤

### 第 1 步：提取事件时间线

```
请从以下章节中提取所有时间相关事件：
- 事件内容
- 时间标记（明确日期/相对时间/模糊时间）
- 涉及角色
- 地点

[粘贴章节]
```

### 第 2 步：建立时间轴

AI 输出结构化时间线：
```
Day 1 早晨：A 离开家乡
Day 1 傍晚：A 到达城镇（合理：距离50里）
Day 3：A 遇见 B（间隔2天，合理）
Day 3 同时：C 在京城收到信（⚠️ 信从城镇到京城需要5天，矛盾！）
```

### 第 3 步：检测矛盾

```
请检查以下时间线是否有矛盾：
1. 角色是否在同一时间出现在不同地点
2. 旅行时间是否合理
3. 季节/天气描写是否前后一致
4. "三天后""一个月前"等相对时间是否自洽

[时间线数据]
```

### 第 4 步：管理平行时间线

```
我的小说有两条平行时间线：
A线（现代）：第1,3,5,7章
B线（古代）：第2,4,6,8章
请确保：
1. 两条线各自的时间逻辑自洽
2. 交汇点的时间对应正确
3. 信息传递的时间差合理
```

## 技巧提示

1. **建立日历**：长篇写作前建立完整日历表
2. **旅行时间**：提前查好地点间的合理旅行时间
3. **季节标记**：用植物、天气、节日暗示时间流逝
4. **时间锚点**：每章开头用明确时间标记锚定
