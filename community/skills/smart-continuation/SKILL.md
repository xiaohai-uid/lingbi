# 智能续写

> 根据前文语境和风格自动续写下一段落，保持文风一致性。

## 适用场景

- 写作卡壳时，让 AI 帮你续写下一段
- 需要保持特定文风的连续创作
- 快速生成初稿，后续手动润色

## 使用步骤

### 第 1 步：打开文档

在灵笔中打开你要续写的章节文档，确保光标位于需要续写的位置。

### 第 2 步：选中文本

选中最后 1-3 段作为续写上下文（AI 会基于这些内容推断后续走向）。

### 第 3 步：触发续写

点击右侧 AI 面板中的 **「续写」** 按钮，或在对话框输入：

```
请根据以上内容续写下一段，保持相同的文风和叙事节奏。
```

### 第 4 步：调整参数

- **温度**：0.7-0.9（越高越有创意，越低越稳定）
- **最大长度**：建议 500-1000 字
- 如果续写方向不对，可以补充提示：`续写方向：主角发现真相后决定...`

### 第 5 步：采纳或修改

- 满意：直接点击「插入到文档」
- 部分满意：复制需要的段落，手动调整
- 不满意：点击「重新生成」或修改提示词

## 高级用法

### 指定续写方向
```
续写下一段。要求：
1. 引入一个新角色（女主角的师父）
2. 氛围从轻松转为紧张
3. 结尾留一个悬念钩子
```

### 多版本对比
```
请用三种不同风格续写：
A. 紧张悬疑风
B. 温情细腻风
C. 幽默诙谐风
```

### 保持特定视角
```
以第一人称「我」的视角续写，保持内心独白风格。
```

## 技巧提示

1. **上下文越长越好**：选中 2-3 段比只选 1 句效果好很多
2. **分次续写**：每次续写 300-500 字，比一次生成 2000 字质量更高
3. **及时修正**：如果 AI 续写偏离，立即指出：`不对，这里应该...`
4. **正典辅助**：在 Canon 中维护好角色设定，AI 续写时会自动参考

## 常见问题

**Q: 续写内容跟前面风格不一致？**
A: 在提示中明确说明：`保持与上文相同的文风，包括短句为主、少用形容词的特点。`

**Q: 续写太短/太长？**
A: 指定字数：`续写约 400 字的一段。`

**Q: 续写方向完全错误？**
A: 提供更多上下文和明确方向，或先保存版本再尝试。
