# Markdown 格式化

> 智能格式化 Markdown 文档，统一标题层级和列表样式。

## 适用场景

- 统一项目内所有文档的格式
- 修复混乱的 Markdown 结构
- 从纯文本转换为结构化 Markdown
- 导出前的最终格式整理

## 使用步骤

### 第 1 步：提交格式化请求

```
请格式化以下 Markdown 文档：
1. 统一标题层级（# → ## → ###，不跳级）
2. 列表样式统一（- 或 *，不混用）
3. 段落间空行规范
4. 代码块标记语言类型
5. 表格对齐

[粘贴文档]
```

### 第 2 步：指定格式规范

```
格式规范：
- 标题：# 一级 / ## 二级 / ### 三级
- 列表：统一用 - 
- 强调：**粗体** 和 *斜体*
- 引用：> 前缀
- 代码：```语言名
- 段落间：一个空行
```

### 第 3 步：应用到项目

格式化完成后，将结果粘贴回灵笔文档中。

## 技巧提示

1. **导出前格式化**：确保导出为 MD/TXT 时格式整洁
2. **章节分离**：每个章节一个文档，避免单文件过长
3. **元数据头**：可以在文档开头添加 YAML front matter
