# 风格蒸馏

> 分析选中文本的写作风格特征，提取语言模式、句式结构和修辞手法。

## 适用场景

- 学习优秀作品的写作风格
- 建立自己的风格档案
- 让 AI 续写时模仿特定风格
- 检测自己的文风是否一致

## 使用步骤

### 第 1 步：选择分析文本

在灵笔中打开一篇你想分析风格的文章（可以是自己的作品或参考作品）。

### 第 2 步：打开 AI 面板

点击右侧 AI 助手面板，确保当前已连接 AI 服务（SenseNova/DeepSeek/OpenAI 等）。

### 第 3 步：发起风格分析

在对话框输入：

```
请分析以下文本的写作风格，包括用词特点、句式结构、修辞手法和节奏感：

[粘贴或选中的文本]
```

或直接点击 AI 面板的 **「风格分析」** 快捷按钮。

### 第 4 步：阅读分析报告

AI 会输出结构化报告，包含：
- 📊 用词特点（词汇丰富度、高频词）
- 📐 句式结构（长短句比例、复杂度）
- 🎭 语气语调（正式/口语、情感色彩）
- ✨ 修辞手法（比喻、排比等使用频率）
- 🎵 节奏感（叙述密度、高潮分布）

### 第 5 步：应用风格

将分析结果用于：
1. **续写参考**：`请模仿上述风格续写...`
2. **自我对比**：分析自己不同章节的风格差异
3. **风格档案**：保存到 Canon 正典中作为角色/作品风格参考

## 高级用法

### 对比分析
```
请对比以下两段文本的风格差异：
文本A：[章节1片段]
文本B：[章节5片段]
分析风格是否有偏移，给出统一建议。
```

### 提取风格模板
```
基于分析结果，生成一个「风格模板」，包含：
1. 句式规则（如：短句为主，每段不超过3句）
2. 用词偏好（如：偏好动词驱动，少用形容词）
3. 节奏模式（如：叙述-对话-叙述 交替）
后续续写时请严格遵循此模板。
```

## 技巧提示

1. **样本量**：至少 500 字的文本才能得出有意义的风格分析
2. **多段对比**：分析 3-5 个不同章节，找出稳定风格特征
3. **保存结果**：将风格报告存入 Canon，后续 AI 功能自动参考
