# 中英翻译

> 高质量中英文互译，保留文学风格和语境。

## 适用场景

- 快速中英互译
- 翻译英文写作参考资料
- 将中文作品片段翻译为英文
- 检查英文表达的准确性

## 使用步骤

### 第 1 步：输入翻译请求

```
翻译为英文（文学风格）：
[中文文本]
```

或：

```
翻译为中文（保持文学性）：
[英文文本]
```

### 第 2 步：指定要求

- **直译 vs 意译**：`请意译，保持意境而非逐字对应`
- **风格**：`翻译风格偏海明威（简洁有力）`
- **术语**：`"修仙"统一翻译为"cultivation"`

### 第 3 步：迭代修正

```
第二段的翻译太生硬了，请更文学化一些。
"他的心碎了" 不要翻译为 "his heart broke"，
试试 "something inside him shattered"。
```

## 技巧提示

1. **提供上下文**：前后段落一起给，翻译更准确
2. **说明读者**：`目标读者是英语母语者` vs `英语学习者`
3. **保留注释**：文化概念可以加译者注
