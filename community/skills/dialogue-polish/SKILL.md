# 对话润色引擎

> 根据角色人设优化对话，确保每个角色声音独特，检测口癖和潜台词。

## 适用场景

- 让不同角色的对话更有辨识度
- 检测对话是否"千人一面"
- 为角色添加独特的语言习惯
- 增加对话中的潜台词和言外之意

## 使用步骤

### 第 1 步：准备角色设定

确保 Canon 正典中已有角色条目，包含性格、身份、说话习惯等信息。

### 第 2 步：选中对话段落

在编辑器中选中需要润色的对话段落（建议包含 2 个以上角色的交互）。

### 第 3 步：发起润色

在 AI 面板输入：

```
请润色以下对话，要求：
1. 角色A（老江湖，说话简短有力，爱用反问句）
2. 角色B（书生，文绉绉，喜欢引经据典）
让每个人的说话方式更有辨识度。

[粘贴对话]
```

### 第 4 步：对比修改

AI 会输出润色后的对话，并标注修改理由：
- 🔤 用词调整（符合角色身份）
- 🎭 语气变化（体现性格差异）
- 💬 潜台词添加（言外之意）
- ⚡ 口癖设计（标志性表达）

### 第 5 步：迭代优化

```
角色A的台词还是太文雅了，他是个粗人，再口语化一些。
角色B可以加入一句口头禅："依小生之见..."
```

## 高级用法

### 批量检测
```
请检查以下章节中所有对话，标记"声音雷同"的段落：
[粘贴整章]
输出格式：位置 + 问题 + 修改建议
```

### 潜台词设计
```
为以下对话添加潜台词层：
表面：两人在讨论天气
实际：A在试探B是否知道秘密
[对话内容]
```

## 技巧提示

1. **先定人设再润色**：角色设定越详细，AI 润色越精准
2. **口癖不要过度**：每个角色 1-2 个标志性表达即可
3. **潜台词适度**：不是每句话都需要言外之意
