# 词汇疲劳检测器

> 统计项目级用词频率，标记过度使用的词汇和表达，推荐同义词替换。

## 适用场景

- 检测自己是否反复使用某些词汇
- 发现"口癖"级别的重复表达
- 获取同义词替换建议
- 提升文本的词汇丰富度

## 使用步骤

### 第 1 步：提交文本检测

```
请统计以下文本中的高频词汇和表达：
1. 列出出现超过5次的形容词/副词
2. 标记重复使用的句式
3. 找出"口癖"表达（如"不由得""竟然""缓缓"）
4. 给出丰富度评分

[粘贴文本，建议2000字以上]
```

### 第 2 步：查看疲劳报告

AI 输出：
```
⚠️ 高频词汇警告：
- "缓缓" 出现 12 次 → 建议：徐徐/慢慢/不紧不慢/从容
- "竟然" 出现 9 次 → 建议：居然/没想到/出乎意料/谁知
- "不由得" 出现 8 次 → 建议：忍不住/情不自禁/下意识

⚠️ 重复句式：
- "他/她 + 动词 + 了一下" 出现 7 次
- "一种...的感觉" 出现 5 次
```

### 第 3 步：获取替换方案

```
请为以下高频词提供替换方案（保持语境）：
1. "缓缓"（12次）→ 根据具体语境给出不同替换
2. "目光"（8次）→ 眼神/视线/眸子/一瞥...
3. "心中一紧"（6次）→ 不同紧张程度的表达
```

### 第 4 步：批量优化

```
请将以下段落中的重复用词替换为多样化表达，
保持原意不变，每个替换标注理由：

[问题段落]
```

## 常见"疲劳词"清单

| 类别 | 高频词 | 替代方向 |
|------|--------|---------|
| 动作 | 缓缓、微微、轻轻 | 具体化动作描写 |
| 情感 | 心中一紧、不禁 | 用行为暗示情感 |
| 语气 | 竟然、居然、没想到 | 减少惊讶标记 |
| 描写 | 目光、眼眸、瞳孔 | 变换视角和感官 |

## 技巧提示

1. **全文统计**：单章看不出问题，要整本统计
2. **不是全换**：偶尔重复是正常的，过度才需修改
3. **建立禁词表**：把自己的高频词列入"尽量避免"清单
