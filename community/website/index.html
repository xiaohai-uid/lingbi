AI 赋能的小说创作

灵笔是一款面向小说作者的开源桌面写作工具，融合 AI 辅助创作与专业的写作管理功能。

⬇ 下载 v2.0 📖 查看文档 🧩 Skill 市场

核心功能

✍️

WYSIWYG 编辑器

基于 flutter_quill 的所见即所得富文本编辑，支持 Markdown 快捷键和实时预览。

🤖

AI 写作助手

智能续写、风格分析、小说结构拆解，支持 DeepSeek/OpenAI/Claude/商汤等模型。

📚

世界构建

角色、地点、传说、情节线索管理，支持语义搜索和关系图谱可视化。

🎨

故事画布

可视化情节节拍编排，力导向/树形/环形布局，拖拽排序，模板快速启动。

💾

自动保存

30 秒定时自动保存 + Ctrl+S 快捷键，版本历史支持预览和恢复到任意版本。

🧩

Skill 市场

从社区安装 Skill 扩展功能，一键安装/卸载，支持 Skill 自动更新。
