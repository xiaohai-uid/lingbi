# 维护文档模板

## 人物库模板

```markdown
# 人物库

## 主角
- 姓名：
- 性别/年龄：
- 身份/职业：
- 性格特征：
- 核心驱动力：
- 金手指/特殊能力：

## 重要配角
- 姓名/关系：
- 作用：

## 反派
- 姓名：
- 与主角的冲突：
```

## 世界观模板

```markdown
# 世界观

## 世界背景
- 时代/地点：
- 核心规则：

## 力量体系
- 等级划分：
- 突破条件：

## 势力格局
- 主要势力：
- 核心矛盾：
```

## 章节摘要模板

```markdown
# 章节摘要

## 第X章 标题
摘要：[一句话概括本章主要事件]
关键变化：[人物状态/关系/设定的变化]
```
