# 灵笔 v5.0 愿景差距分析

> 基于 2026-07-10 用户访谈

---

## 愿景 vs 现状

| 维度 | 愿景目标 | 当前状态 | 差距 | 难度 |
|------|----------|----------|:----:|:----:|
| **生成流程体验** | 分步确认式：创意→梗概→大纲→正文，每一步有漂亮的展示 | `_doGenerate()` 只有 SnackBar，结果在简陋的 AlertDialog 里 | 🔴 极大 | 小 |
| **长篇稳定性** | 500万字不崩人设，伏笔可回收 | 有角色一致性检测 + 蝴蝶效应分析，但只在事后检测，不自动保证 | 🟡 中 | 大 |
| **流式生成** | 逐字逐句看到 AI 写作过程，像 NovelAI 一样 | Layer3 支持 Stream 但未串联，UI 无流式展示 | 🔴 极大 | 中 |
| **编辑器体验** | 专业写作编辑器，沉浸式、无干扰 | flutter_quill 基础编辑器，无字数统计、无目标管理 | 🟡 中 | 中 |
| **UI 整体质感** | 精致、流畅、有"创作感"的 UI | 功能齐全但UI粗糙，生成过程"不美妙" | 🔴 极大 | 中 |
| **网文专项** | 爽文模板、节奏控制、日更 1 万字辅助 | 基础类型选项 + 风格选项，无专项优化 | 🟡 中 | 大 |

## 当前最大问题（按用户反馈排序）

1. **🔴 UI 太丑** — 生成过程、编辑器、整体质感都不够好
2. **🔴 生成质量** — AI 写出来的东西不是想要的
3. **🟡 流式体验** — 看不到生成过程，没有沉浸感

## 建议路线

```
第1步（立即）: UI Demo → 用户确认 → 落地
第2步（Sprint 1）: 生成流程体验大改（流式 + 漂亮UI + 分步确认）
第3步（Sprint 2）: 编辑器体验升级（字数统计、沉浸模式、目标管理）
第4步（Sprint 3+）: 长篇稳定性系统（向量记忆、自动一致性保证）
```
