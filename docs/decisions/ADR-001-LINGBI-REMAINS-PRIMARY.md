# ADR-001: 灵笔继续作为唯一主项目

## 状态

已接受 (2026-07-24)

## 背景

灵笔当前面临两个对照项目的竞争压力：
- OpenWrite：成熟的 CLI 长篇小说写作引擎（Python，v5.8.0）
- DreamEngine/幻海Opus：公开信息不可验证

需要决定灵笔的定位和与对照项目的关系。

## 决策

**灵笔继续作为唯一主项目。**

不允许：
- 废弃灵笔
- 整体迁移到另一个项目
- 把灵笔仅作为其他项目的 UI
- 同时维护两套或三套正式小说数据

可以从对照项目吸收设计思想，但必须用 Dart/Flutter 重新实现。

## 理由

1. 灵笔已有可运行的 Flutter 桌面端（Quill WYSIWYG + 三栏布局 + 多 Provider AI）
2. 灵笔的桌面 GUI 体验是 OpenWrite（CLI-first）不具备的差异化优势
3. 用户以 Windows 桌面端为主要使用环境
4. 灵笔已有便携项目格式（.lingbi/project.json + .md），数据可迁移性好
5. 切换到 Python CLI 不符合用户的产品形态需求

## 后果

- 正面：保持产品方向一致，不分散精力
- 正面：保留桌面 GUI 差异化
- 负面：需要自行实现 OpenWrite 已有的长篇连续性机制
- 负面：不能直接复用 OpenWrite 代码（许可证不明 + 语言不同）

## 来源

- 用户约束："灵笔必须继续作为主项目"
- 圆桌会议投票：13/13 赞成
