# ADR-005: 世界线隔离 (Worldline Isolation)

## 状态

已接受 (2026-07-24)

## 背景

灵笔的未来差异化能力是"世界线选择"——让作者探索"如果主角在第三章做了不同的选择，故事会怎样发展"。

风险：
- 分支内容可能意外污染正史正文
- 分支中的角色状态可能与正史冲突
- 无限分支导致存储膨胀
- 作者可能混淆候选分支与正式正文

当前灵笔没有任何世界线相关实现。

## 决策

**世界线（候选未来）与正史严格隔离，只有显式写作+采纳才能推进正史。**

### 铁律

```
1. 生成世界线不能修改正文。
2. 选择世界线不能修改正史。
3. 只有显式写作和采纳动作才能推进正史。
```

### 隔离机制

| 操作 | 写入位置 | 是否影响正史 |
|------|---------|-------------|
| 创建分支 | `.lingbi/candidates/worldlines/{branch_id}/` | 否 |
| 分支内写作 | `.lingbi/candidates/worldlines/{branch_id}/ch_*.md` | 否 |
| 分支内结算 | `.lingbi/candidates/worldlines/{branch_id}/runtime/` | 否 |
| 选择分支 | 只标记 status = selected | 否 |
| 采纳分支 | 触发写作流水线（写→审→采纳→结算） | 是（经过流水线） |
| 分支过期 | 标记 status = expired，移入 archive/ | 否 |

### 生命周期

```
创建 → 活跃 → 选择 → 采纳(经过流水线) → 合并完成
                  → 过期(30天) → 归档
                  → 手动归档
```

### 分叉时快照

创建分支时自动创建 Canon Snapshot：
- 冻结当前正典状态
- 冻结当前运行态
- 记录分叉点章节 ID
- 分支内的所有操作基于快照，不影响正史

### 比较机制

- 并排比较：分支正文 vs 正史正文
- 状态比较：分支角色状态 vs 正史角色状态
- 剧情比较：分支剧情线走向 vs 正史剧情线走向

### 过期规则

- 默认 30 天未操作自动过期
- 过期分支移入 `archive/worldlines/`
- 归档分支可手动恢复
- 最多保留 10 个活跃分支（可配置）

## 理由

1. 用户约束："世界线选择"是灵笔重要差异化能力
2. 用户约束："AI 未经确认不得修改正式正典"
3. 防止分支污染是世界线功能的基本安全保证
4. 经过写作流水线采纳保证合并后的连续性
5. 过期机制防止无限膨胀
6. 快照机制保证分叉点可追溯

## 后果

- 正面：正史永远不会被分支意外污染
- 正面：作者可以安心探索"如果……"
- 正面：分支有过期机制，不会无限膨胀
- 正面：采纳经过流水线保证连续性
- 负面：分支采纳需要额外步骤（不能一键合并）
- 缓解：这是设计意图，不是缺陷——合并必须经过审稿
- 负面：多分支存储占用磁盘
- 缓解：过期归档 + 最多 10 个活跃分支

## 前置依赖

世界线功能（Phase 6）依赖以下机制先完成：
- 候选/正史隔离（Phase 2: Action Surface）
- 写作流水线（Phase 3）
- 采纳机制（Phase 4）
- 快照系统（Phase 2: TransactionService）
