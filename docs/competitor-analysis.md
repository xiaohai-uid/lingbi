## 1. 各平台简介

### 1.1 起点读书 (Qidian) — 作家专区
- 国内最大原创小说平台，作者后台提供完整的创作管理工具
- **核心定位**: 专业化作者创作管理平台
- **AI 能力**: 无原生 AI 生成功能，依赖第三方工具

### 1.2 番茄小说 (Fanqie) — 作者中心
- 字节跳动旗下免费阅读平台，作者后台集成 AI 辅助写作
- **核心定位**: 流量驱动型创作平台
- **AI 能力**: 番茄 AI 写作助手 (基于豆包模型)

### 1.3 NovelAI
- 国际知名的 AI 故事生成平台
- **核心定位**: AI 原生创作工具
- **AI 能力**: 自研模型 + 流式文本生成 + 图像生成

### 1.4 彩云小梦
- 国内最早的 AI 小说生成平台之一
- **核心定位**: AI 交互式故事创作
- **AI 能力**: 自研中文模型 + 流式生成

### 1.5 灵笔 (Lingbi) — 本项目
- Flutter Desktop 小说写作工具
- **核心定位**: AI 赋能的小说创作桌面工具
- **AI 能力**: 三层生成管线 (梗概→细纲→正文) + 质量评审

## 3. 关键差距总结

### P0 — 必须尽快补齐

| 差距 | 详情 | 参考竞品 |
|------|------|----------|
| **❌ AI 生成进度反馈** | 生成时仅显示"AI 正在创作…"SnackBar，无流式输出、无字数、无步骤、无可取消 | NovelAI / 彩云小梦 — 都有流式+进度 |
| **❌ 实时字数统计** | 编辑器内标注"待实现"，Dashboard 有总计但编辑器内无实时统计 | 起点/番茄 — 编辑器实时显示 |
| **🟡 生成管线未串联** | `generateNovel()` 只走 Layer1+2，Layer3 流式生成未接入生成流程 | 番茄 — 直接生成正文 |

### P1 — 重要增强

| 差距 | 详情 |
|------|------|
| **错别字/语法检查** | 起点/番茄都有基础校对，灵笔没有 |
| **拖拽排序** | 卷/章/场景不支持拖拽重排 |
| **批量操作** | 不支持批量移动、删除章节 |
| **生成中断** | AI 生成过程中无法取消/暂停 |

### P2 — 锦上添花

| 差距 | 详情 |
|------|------|
| **存稿箱/定时发布** | 作为桌面写作工具可选 |
| **平台一键发布** | 对接起点/番茄 API 发布 |
| **读者数据/运营** | 上线后为平台接入预留 |
| **敏感内容审查** | 上线前需补充 |

## 4. 独家优势

灵笔相比竞品有以下**独有功能**，应保持和强化：

| 功能 | 说明 |
|------|------|
| ✅ 五级 World→Work→Volume→Chapter→Scene 层级 | 比起点/番茄更细粒度的结构管理 |
| ✅ 角色一致性检测 | 竞品均无此功能 |
| ✅ Hook 密度/爽点分析 | 竞品均无此功能 |
| ✅ 蝴蝶效应分析 | 竞品均无此功能 |
| ✅ 多模型支持 (DeepSeek/OpenAI/Claude) | 灵活切换，不绑定单一模型 |
| ✅ 版本历史快照+恢复 | 点/番有但 NovelAI/彩云没有 |
