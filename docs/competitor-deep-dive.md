# 深度竞品功能拆解 — 起点 / 番茄 / NovelAI / 其他

> 编制: 2026-07-10
> 方法: 平台公开文档 + 作者后台评测 + 用户反馈 + 功能实测
> 目的: 逐平台、逐功能拆解，找出灵笔的差距

---

## 1. 起点作家专区 (Qidian Author)

起点是最大的付费网文平台，其作家专区的功能核心是**作品运营+数据驱动**，而非 AI 生成。

### 1.1 创作管理
| 功能 | 详情 | 灵笔对标 |
|------|------|:--------:|
| **多作品管理** | 作者后台列表，可切换管理多部作品 | ✅ World 级别 |
| **分卷管理** | 卷-章两级结构，支持拖拽排序 | 🟡 五级更细但无拖拽 |
| **存稿箱** | 可预存最多 100 章，定时自动发布 | ❌ **缺失** |
| **定时发布** | 设置未来某个时间点自动发布章节 | ❌ **缺失** |
| **章节草稿** | 每章可存多个草稿版本 | ❌ 只有当前版本 |
| **敏感词检测** | 发布前自动检测违规内容 | ❌ **缺失** |
| **自动排版** | 段落缩进、标点修正 | ❌ **缺失** |

### 1.2 数据看板
| 功能 | 详情 | 灵笔对标 |
|------|------|:--------:|
| **实时数据** | 收藏、订阅、追读实时更新 | ❌ 桌面工具天生缺失 |
| **读者画像** | 年龄、性别、地域分布 | ❌ 缺失 |
| **收入统计** | 稿费明细、打赏、月票榜 | ❌ 缺失 |
| **转化分析** | 从点击→收藏→订阅的转化漏斗 | ❌ 缺失 |
| **对比数据** | 同期作品数据对比 | ❌ 缺失 |

### 1.3 读者互动
| 功能 | 详情 |
|------|------|
| **本章说** | 读者在每章末尾评论 |
| **推荐票/月票** | 读者投票机制 |
| **打赏** | 读者直接付费支持 |
| **催更** | 读者催更按钮，达到一定数量作者需加更 |
| **角色比心** | 读者可为角色点赞 |

### 1.4 起点 vs 灵笔 — 核心差异

起点作家专区**不做 AI 生成**，它是一个**运营平台**。灵笔作为创作工具，应该参考的数据功能：
- 写作字数统计（日/周/月趋势）
- 作品收入/读者数据分析的**预留接口**
- 章节版本管理

## 2. 番茄小说作者中心 (Fanqie Author)

番茄是字节系免费阅读平台，作者后台引入了 **AI 辅助写作**（基于豆包模型）。

### 2.1 AI 写作功能
| 功能 | 详情 | 灵笔对标 |
|------|------|:--------:|
| **AI 续写** | 选中文本后 AI 续写下一段 | ✅ 有但未完善 |
| **AI 润色** | 改写/扩写/缩写选中文本 | 🟡 有改写入口 |
| **AI 取名** | 生成角色名/地名/招式名 | ❌ **缺失** |
| **AI 大纲生成** | 输入创意→生成章节大纲 | ✅ Layer2 有 |
| **AI 人设生成** | 生成角色设定和关系 | ✅ 有 |
| **AI 世界观生成** | 生成世界设定 | 🟡 有但未独立 |
| **AI 文风检测** | 分析当前文风并提出建议 | ❌ **缺失** |

### 2.2 番茄 vs 灵笔 — 关键差异

番茄的 AI 辅助是**轻量级、高频次**的——作者写一段，AI 帮一段。灵笔目前的 AI 更偏向**一次性长篇生成**。

灵笔缺少的:
- **AI 取名** — 生成角色名、地名、功法名
- **AI 润色/扩写** — 对已有文本进行局部改写
- **AI 文风检测** — 分析当前写作风格并给出建议

## 3. NovelAI

NovelAI 是国际领先的 AI 故事生成平台，**灵笔最直接的对标对象**。

### 3.1 生成体验
| 功能 | NovelAI | 灵笔 |
|------|:-------:|:----:|
| **流式生成** | ✅ 逐 token 流式输出 | 🟡 Layer3 有但未串联 UI |
| **生成进度** | ✅ 进度条 + 字数和 token 计数 | ❌ 只有 SnackBar（已改为 ProgressDialog） |
| **可中断** | ✅ 一键停止生成 | 🟡 最近刚添加取消按钮 |
| **回溯编辑** | ✅ 可回溯到生成文本的任何位置修改 | ❌ **缺失** |
| **生成参数** | ✅ 温度/重复惩罚/长度/上下文等精细控制 | ❌ **缺失** |
| **记忆系统** | ✅ 长文本 Memory 自动摘要 | ❌ **缺失** |

### 3.2 世界构建
| 功能 | NovelAI | 灵笔 |
|------|:-------:|:----:|
| **Lorebook** | ✅ 键值对式世界设定，AI 自动匹配引用 | ❌ **缺失** |
| **角色卡片** | ✅ 角色设定卡片 | 🟡 有角色管理但不如 Lorebook 智能 |
| **图片生成** | ✅ 内置 AI 绘图 | ❌ **缺失** |
| **导入导出** | ✅ 支持完整导入导出故事和设定 | 🟡 部分格式 |

### 3.3 NovelAI vs 灵笔 — 核心差异

| 差距 | 影响 | 优先级 |
|------|------|:------:|
| **Lorebook（世界设定自动引用）** | AI 生成时自动读取角色/地点/规则设定，保证一致性 | **P0** |
| **记忆系统** | 长文本自动摘要，避免超出上下文窗口 | **P1** |
| **生成参数控制** | 用户调节温度/重复惩罚等 | P2 |
| **图片生成** | 角色/场景可视化 | P2 |
| **回溯编辑** | 生成文本中任意位置修改 | P1 |

## 4. 彩云小梦

国内最早的 AI 小说生成平台之一，主打**交互式故事创作**。

### 4.1 特色功能
| 功能 | 详情 |
|------|------|
| **交互式生成** | AI 生成一段 → 用户选择方向 → AI 继续 |
| **多分支故事** | 支持故事树，不同选择走向不同剧情 |
| **角色对话生成** | 直接生成角色之间的对话 |
| **场景描写生成** | 生成特定场景的环境描写 |

### 4.2 对灵笔的启发

彩云小梦的**交互式生成**值得参考——不是让 AI 一口气生成整部小说，而是：
1. AI 生成一段（~500字）
2. 用户阅读后给出方向指示
3. AI 根据方向继续生成

## 5. Sudowrite / 写匠 / 其他

### 5.1 Sudowrite
专业的英文 AI 写作辅助工具，特色功能:
- **Story Engine**: 输入 premise → AI 生成完整故事大纲和章节
- **Beat Sheet**: 三幕式/英雄之旅等结构模板
- **扩写/改写/缩写**: 精细的文本操作
- **写作目标**: 设置每日字数目标并跟踪进度

### 5.2 写匠 (AI Writer)
中文 AI 写作工具，特色功能:
- **AI 模板**: 30+ 网文类型模板（玄幻/言情/悬疑等）
- **AI 取名**（同番茄）
- **写作日历**: 日更追踪

## 6. 综合差距矩阵

### ❌ 灵笔完全缺失的功能（P0）

| 功能 | 来源 | 说明 |
|------|------|------|
| **Lorebook / 世界设定自动引用** | NovelAI | AI 生成时自动提取相关设定，保证一致性 |
| **AI 取名** | 番茄/写匠 | 生成角色名、地名、功法名 |
| **敏感词/内容审查** | 起点/番茄 | 发布前检测违规内容 |
| **定时发布/存稿箱** | 起点/番茄 | 设置发布时间 |
| **交互式生成** | 彩云小梦 | AI 生成一段→用户选择→继续 |

### 🟡 灵笔功能薄弱项（P1）

| 功能 | 问题 | 改进方向 |
|------|------|----------|
| **AI 润色/扩写/改写** | 只有入口但未完善 | 对已有文本选区操作 |
| **生成参数控制** | 无温度/长度/上下文控制 | 增加生成参数面板 |
| **章节拖拽排序** | 计划但未实现 | 拖拽重排卷/章/场景 |
| **侧边栏章节大纲** | 只有标题列表 | 显示字数、状态、修改时间 |
| **写作文风检测** | 完全缺失 | 分析并给出写作建议 |

### ✅ 灵笔已有但需强化的功能

| 功能 | 现状 | 强化方向 |
|------|------|----------|
| 五级 World→Work→Volume→Chapter→Scene | ✅ 比竞品更细 | 增加拖拽和批量操作 |
| 角色一致性检测 | ✅ 独有 | 从检测升级到自动保证 |
| 蝴蝶效应分析 | ✅ 独有 | 增加可视化展示 |
| 角色关系图谱 | ✅ 独有 | 增加交互编辑 |
| 版本历史 | ✅  | 增加草稿分支 |
| 多模型支持 | ✅  | 增加自定义模型 |

## 7. 核心结论

灵笔的**独有优势**（竞品没有的）：
1. **五级内容层级** — 比起点/番茄的卷-章两级更精细
2. **角色一致性检测** — AI 自动检测人设是否崩了
3. **Hook 密度/爽点分析** — 量化分析文本节奏
4. **蝴蝶效应分析** — 时间线变更影响推演
5. **版本历史快照** — 每次保存自动存档

灵笔的**最大短板**（最该优先修的）：
1. **🔴 Lorebook 缺失** — 没有世界设定自动引用机制，AI 生成的文本容易前后矛盾
2. **🔴 AI 生成体验粗糙** — 参数不可调、过程无细节展示、不可回溯编辑
3. **🟡 编辑辅助缺失** — 无 AI 续写/润色/取名/扩写等细粒度辅助功能
4. **🟡 交互式生成缺失** — 只有一键全自动，没有边看边改的交互模式
