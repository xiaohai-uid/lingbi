# ADR-0005: 引导流程 UI 容器 — 混合模式

## 状态

已接受 (2026-07-25)

## 背景

OpenWrite 是 Web 应用，引导对话占据主界面。灵笔是 Flutter Desktop 三栏布局（sidebar + editor + aiPanel），需要决定引导流程的 UI 容器。

## 决策

采用混合模式（方案 C）：

1. **首次创建项目 → 全屏引导模式**
   - 覆盖最关键的前两步：世界观构建 + 核心角色创建
   - 类似 Onboarding Wizard 的沉浸式体验
   - 完成后退出全屏，回到正常三栏布局

2. **后续引导 → AI Panel（右栏）**
   - 大纲生成、章节规划、伏笔管理等后续步骤在右侧 AI 面板中进行
   - 面板顶部显示引导进度条（世界观 ✓ → 角色 ✓ → 大纲 ● → 章节 ○）
   - Editor 区域实时展示引导产出（AI 一边问一边往编辑器里写）

3. **用户随时可跳出**
   - 全屏引导阶段可"跳过"或"稍后再说"
   - AI Panel 引导阶段可暂停引导进入自由对话

## 后果

- 正面：新用户首次体验沉浸（= OpenWrite 新建项目体验）；后续不打断正常创作布局
- 负面：需实现两种 UI 容器之间的状态无缝衔接（全屏→面板，引导进度不丢失）
- 实现：全屏引导和面板引导共用同一个 GuidedFlowEngine 实例，只是渲染容器不同
