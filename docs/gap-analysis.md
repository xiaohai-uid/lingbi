## 2. P0 级问题 — 必须立即修复

### 🔴 P0-1: AI 生成无进度反馈

| 项目 | 详情 |
|------|------|
| **问题** | 生成小说时仅显示 "AI 正在创作…" SnackBar，固定 30 秒 |
| **竞品参考** | NovelAI: 流式输出 + token 进度条 + 可取消; 彩云小梦: 实时字数+阶段指示 |
| **代码位置** | `wg_workspace_page.dart:1055-1069` — `_doGenerate()` |
| **根因** | `generateNovel()` 返回 `Future<String>`（非流式），UI 无法获取中间状态 |
| **影响** | 用户不知道生成进度、已生成字数、当前生成阶段，体验极差 |

**修复路径:**
1. 将 `generateNovel()` 改为返回 `Stream<String>`（Layer3 已支持 Stream，只需串联）
2. UI 端用 `StreamBuilder` 监听流式输出，实时更新字数和内容预览
3. 增加阶段指示: Layer1(梗概) → Layer2(细纲) → Layer3(正文)
4. 增加取消按钮 → `StreamSubscription.cancel()`

### 🔴 P0-2: 章节切换显示错误内容

| 项目 | 详情 |
|------|------|
| **问题** | 点击侧边栏不同章节，编辑器始终显示同一份内容 |
| **竞品参考** | 所有平台切换章节即切换编辑内容 |
| **代码位置** | `wg_editor_page.dart:124-140` (`_loadDocument`) + `:275` (onTap) |
| **根因** | `_loadDocument()` 取所有文档的第一个，无视当前选中章节 |
| **影响** | 用户无法编辑不同章节的内容，项目管理功能名存实亡 |

**修复路径:**
- 详见 `docs/bug-report.md` Fix 1-3

### 🔴 P0-3: 生成管线未串联

| 项目 | 详情 |
|------|------|
| **问题** | `generateNovel()` 只走 Layer1(梗概) + Layer2(细纲)，不走 Layer3(正文生成) |
| **竞品参考** | 番茄AI写作: 直接生成正文; NovelAI: 生成完整故事 |
| **代码位置** | `services/novel/novel_service.dart:34-63` — `generateFull()` |
| **根因** | `NovelService.generateFull()` 只返回 `NovelGenerationResult`(梗概+细纲)，不调用 `streamChapter()` |
| **影响** | 点击"生成小说"后只得到大纲，没有实际小说正文 |
