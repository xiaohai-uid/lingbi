## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `xiaohai-uid/lingbi`. External PRs are treated as a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles use default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo: `CONTEXT.md` at root + `docs/adr/`. See `docs/agents/domain.md`.
