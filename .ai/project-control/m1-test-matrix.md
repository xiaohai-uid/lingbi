# /project-control M1 测试矩阵

每个用例包含：前置条件、输入、执行动作、预期输出、禁止行为、验证方式。

## 正常路径

### TC-01：用户级配置成功定位

| 项目 | 内容 |
|------|------|
| 前置条件 | `~/.project-control/config.json` 存在且指向有效 Vault；Vault 中有正确 V2.0 文档 |
| 输入 | `/project-control`（无参数） |
| 执行动作 | 按优先级链定位，找到用户级配置，读取文档 |
| 预期输出 | 配置来源报告为 `user-config`；文档版本 `2.0`；生效等级 `bootstrap` |
| 禁止行为 | 不得尝试更低优先级来源；不得修改配置文件 |
| 验证方式 | 输出包含 `配置来源: user-config`；Git 工作区无变化 |

### TC-02：显式路径覆盖

| 项目 | 内容 |
|------|------|
| 前置条件 | 用户级配置存在；另有独立测试文档在 `/tmp/test-governance.md` |

| 执行动作 | 直接使用显式路径，跳过所有其他来源 |
| 预期输出 | 配置来源报告为 `explicit`；读取的是测试文档 |
| 禁止行为 | 不得读取用户级配置；不得报告 user-config |
| 验证方式 | 输出包含 `配置来源: explicit` |

### TC-03：环境变量覆盖

| 项目 | 内容 |

### TC-04：仓库级覆盖
