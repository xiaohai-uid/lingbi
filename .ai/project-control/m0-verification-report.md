## 五、设计冻结声明

以下 ADR 自本报告起默认冻结：

- ADR-0003：单源分发与激活架构
- ADR-0004：分层状态模型与证据驱动判定
- ADR-0005：四档模式路由与 Direct Change
- ADR-0006：治理层与执行层分离
- ADR-0007：分层合规体系
- ADR-0008：保留历史的阶段重开
- ADR-0009：渐进交付路线与 Bootstrap

重开条件（仅以下情况允许）：

1. ADR 之间存在无法同时满足的冲突；
2. M1 无法在现有 Agent/Skill 机制中实现；
3. 安全、数据或权限模型存在严重缺陷；
4. 实际原型证伪关键架构假设；
5. 实施成本明显超过当前收益；
6. 用户明确要求重新讨论。

## 六、M1 启动前置条件

用户批准本报告后，M1 实施前还需：

1. 创建独立 `project-control` Git 仓库；
2. 确认 Codex Skill 目录路径；
3. 创建用户级配置 `~/.project-control/config.json`；
4. 确认 Python 3.10+ 可用。
